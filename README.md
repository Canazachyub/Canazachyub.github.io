# Atlas de Medicina · UNA Puno

Portal que reúne todos los atlas interactivos en un solo lugar, con un buscador de láminas
que abre cada una directo en su atlas original (`<atlas>/#/l/<n>`).

Para actualizar después de cambiar un atlas: `py tools/construir.py` (lee los atlas publicados
y regenera `datos.js` y las miniaturas de `img/mini/`).
